# 📉 Customer Churn Prediction

## 📊 Project Overview

This project focuses on predicting **customer churn** using Machine Learning.

The model analyzes customer information such as **tenure, contract type, payment method, monthly charges, and other customer attributes** to identify customers who are likely to leave a service.

An interactive **Streamlit web application** is also included to make churn predictions easily.

## 🎯 Objectives

* Predict whether a customer is likely to churn.
* Analyze factors that contribute to customer churn.
* Perform data cleaning and exploratory data analysis.
* Train and evaluate a Machine Learning classification model.
* Build an interactive interface for making predictions.
* Visualize important churn patterns and customer insights.

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data manipulation
* **NumPy** – Numerical computation
* **Scikit-learn** – Machine Learning
* **Matplotlib & Seaborn** – Data visualization
* **Streamlit** – Web application
* **Joblib** – Model saving and loading
* **Tableau** – Data visualization and dashboarding

## 🤖 Machine Learning

The project uses a **Random Forest Classifier** to predict customer churn.

## 📈 Features

The application allows users to enter customer information and receive a churn prediction.

The project analyzes factors including:

* Customer tenure
* Monthly charges
* Total charges
* Contract type
* Payment method
* Internet service
* Online security
* Tech support
* Senior citizen status
* Partner/dependent status
* Other customer attributes

## 📊 Model Evaluation

The trained model can be evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
